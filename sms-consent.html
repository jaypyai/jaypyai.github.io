SMS Reminder Consent Script

Verbal opt-in used by Michael Provitera for personal SMS reminders. Recipients: my wife and myself only. This is a non-marketing, personal use case.

The script

Michael: "Hi! This is Michael. I'd like to send you personal reminder texts from my notification number — things like appointment reminders, medication reminders, and household reminders."

Michael: "I'd send roughly a few messages per week, always under 100 per month. Standard message and data rates may apply."

Michael: "If you ever need help, just reply HELP. And if you want to stop receiving these at any time, just reply STOP."

Michael: "Do you agree to receive these reminder texts? Please answer yes or no."

Recipient: "Yes."

Michael: "Great — you're enrolled. You'll get a confirmation text shortly."

What this covers

Service: personal reminder messages (appointments, medication, household) sent by Michael Provitera.

Frequency: a few messages per week, under 100 per month.

Rates: standard message and data rates may apply.

Help: reply HELP at any time.

Opt-out: reply STOP at any time to stop receiving messages.

Consent: explicit verbal "yes" required before any message is sent.
